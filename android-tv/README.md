# JavJaeger TV

原生 Android TV 客户端，通过现有 JavJaeger HTTP API 浏览和播放服务器影视库。支持 Android 6.0（API 23）及以上的 Android TV，使用遥控器方向键、确认键与返回键操作。

**[下载 v0.3.6 测试版 APK](https://github.com/cnlutong/JavJaeger/releases/tag/android-tv-v0.3.6)**。本版加快播放控制层隐藏并进入全屏，支持左右方向键立即后退／快进 30 秒，无需确认，继续支持外挂字幕及样式设置；外挂字幕需要包含字幕接口的服务端。**从 v0.3.5 及更早发布版升级时，需先卸载再安装，服务器地址和字幕偏好需重新设置。v0.3.6 起固定沿用同一签名，后续版本可覆盖升级。** 也可按下方步骤自行构建。

## 使用

1. 在服务器的管理网页中配置媒体目录，扫描影视库并补全封面和资料。
2. 在电视安装 APK，从电视应用列表打开 **JavJaeger TV**。
3. 输入电视可访问的服务器地址，例如 `http://192.168.1.100:8000`，选择“连接服务器”。不要填写电视自身的 `localhost`、服务器文件路径或网盘地址。
4. 浏览海报，按标题、番号或演员搜索。打开详情后选择文件播放；已标记缺失的文件不可选择，多段影片自动顺序播放后续可用文件。

影院采用参考 Apple TV 的深色界面：左侧导航在内容获得焦点时收起，返回导航时展开名称；提供“推荐、全部影片、标签、演员、VR、浏览新片”。搜索按需打开，组合筛选和排序集中在“筛选影片”，“更多”提供刷新、管理和更换服务器。推荐页展示精选影片及最近入库、高清收藏和 VR 横排。横排固定封面高度并按原图比例调整卡片宽度，影片墙采用等宽分列、原图高度的瀑布流；横图、竖图和方图均完整显示，不裁切或拉伸。列表标题与数量、排序信息分行显示。本地详情采用封面与播放资料双栏，右侧可滚动查看文件、简介、演员和标签。焦点以白色轮廓和轻微放大提示，详情关闭后恢复原卡片。本地与新片演员目录展示头像，末行保持固定列宽；影片详情的演员入口也显示照片，选择演员仍进入对应影片墙或叠加浏览条件。暂无可用头像时显示姓名占位。VR 按分辨率分区。

标签页替代原来的系列入口，展示影视库中的实际标签和影片数量，支持搜索、分页和多选。“匹配任一标签”取所选标签的并集，“匹配全部标签”只显示同时包含所有所选标签的影片。结果页可继续组合演员、制作商、分辨率和标签条件，按入库时间、发行日期、体积或番号排序，并逐项移除条件或清空。详情中的演员与标签也可直接进入对应筛选结果。

“浏览新片”与网页浏览页共用 JavBus 列表、演员与标签目录、有码／无码切换及分页接口；详情中的演员、标签、制作商、发行商、导演和系列可叠加筛选。选择“最佳资源播放”后，由服务器选择磁力并等待 115 离线完成，再打开原生播放器。等待支持取消、重试和通过“更多 → 115 播放准备”继续；取消等待不会删除网盘文件。使用前需在服务器管理网页登录 115。

播放器支持遥控器暂停、继续、进度条定位、切换本地播放文件和停止播放。打开播放页即隐藏系统状态栏与导航栏，视频铺满屏幕。标题与操作按钮分行显示，播放按钮和进度条集中在画面下方；播放中约 1.5 秒无操作后，顶部与底部控制层同时隐藏，焦点停在顶部按钮时也会自动隐藏。遥控器操作会重新计时，暂停时控制层保持显示。播放区域按左键立即后退 30 秒、按右键立即快进 30 秒，无需确认；控制层隐藏时同样可用，超出片头或片尾时停在当前文件边界。按上键唤出控制层并进入文件选择，顶部操作栏中的左右键用于按钮导航；按下键唤出进度条并将焦点送入，左右键仍立即定位 30 秒，也可用鼠标或触控直接拖动进度条。定位保留暂停或播放状态。在线单文件播放的上键进入停止按钮。返回详情或浏览页保留查询、筛选和浏览位置。“管理界面”和“在影视库中管理”通过电视的系统浏览器打开服务器管理页；电视没有浏览器时，界面显示可在其他设备访问的地址。

客户端长期保存不含账号、查询参数或片段的服务器地址，以及字幕显示偏好。115 播放等待使用按服务器隔离的内存会话，播放器通过请求头沿用同一会话；进程结束后需重新选择影片，115 Cookie 和下载直链始终留在服务器。它沿用服务器的私有网络访问边界，没有独立认证；带登录的反向代理需要另行适配。地址可使用 HTTP 或 HTTPS，HTTPS 使用系统证书校验。列表、封面与播放地址固定使用同一个服务器，不接收任意服务器本地路径。

视频直接播放原文件，编码与内封音轨、字幕支持取决于电视。本地影片支持同目录、同文件名的 UTF-8 或带 BOM 的 UTF-16 SRT/VTT 外挂字幕，例如 `ABF-017.zh-Hans.srt` 或 `ABF-017.zh-Hans.vtt`。两种格式同名时优先使用 VTT，只显示一条。播放时按需发现字幕，无需重新扫描影视库；默认优先中文字幕。播放器顶部的“字幕：开／关”可用遥控器切换，暂停时也能立即开关；切换字幕保留播放位置，切换分段只加载对应文件的字幕。网页影院和影视库播放也使用相同接口，并可选择字幕语言。

同名 MP4/MKV 等不同版本可以分别使用 `SNOS-377.mp4.zh-Hans.srt` 与 `SNOS-377.mkv.zh-Hans.srt`。服务端仅返回当前视频版本的字幕，并优先使用版本专属字幕，再回退到同一语言的通用字幕。

当前没有实时转码或跨设备观看进度；不支持的编码可先在服务器管理网页完成转码。外挂字幕失败不阻断视频播放，旧服务端仍可播放原文件。

播放器顶部的“字幕样式”提供黑体、衬线体、等宽字体，以及小、标准、大、特大四档字号。底部留白可选 2%、4%、6%、8%、12%，默认为 4%，数值越小越靠近底部。调整即时生效并保存在当前设备，也可恢复默认；暂停、切换分段和重新打开应用后均可沿用设置。字体使用设备内置字体，不额外下载。

## 构建 APK

需要 JDK 21、Android SDK 与网络连接，并恢复下方的固定签名配置。SDK 路径通过 `ANDROID_HOME` 或本机 `local.properties` 的 `sdk.dir` 指定，SDK 平台版本以 `app/build.gradle` 的 `compileSdk` 为准。Gradle Wrapper 会下载固定版本的构建工具和依赖。

在仓库根目录执行：

```bash
cd android-tv
./gradlew verifyTvSigning testDebugUnitTest lintDebug assembleDebug
```

成功后生成 `app/build/outputs/apk/debug/app-debug.apk`。该 APK 为调试构建，适合自用安装和测试；调试与 release 构建都使用 v0.3.6 的固定项目签名，后续发布不得改用新生成的密钥。发布时递增 `versionCode` 并保持 `applicationId` 不变。

没有项目私密签名的贡献者，可显式使用 `./gradlew -PjavjaegerTvDevelopmentSigning=true testDebugUnitTest lintDebug assembleDebug` 进行本机开发。这类包不能覆盖官方安装包，也不能通过 `verifyTvSigning` 发布检查。

启用电视的开发者选项与 ADB 后，安装 APK：

```bash
adb -s <电视序列号> install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以把 APK 复制到电视，通过电视的文件管理器安装。电视端不需要配置下载器、网盘账号或媒体挂载。

### 固定签名与备份

固定签名配置由 `signing.gradle` 读取，默认位于仓库之外的 `/Volumes/dev1/Developer/private/JavJaeger/android-tv/signing.properties`。配置包含 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`；相对的 `storeFile` 路径按配置文件所在目录解析。迁移机器或在其他位置构建时，通过 `JAVJAEGER_TV_SIGNING_PROPERTIES` 指向恢复后的私密配置文件，不把口令放进命令行或版本库。

签名已备份在两处：

- 外置盘私密目录 `/Volumes/dev1/Developer/private/JavJaeger/android-tv/`，包含 `javjaeger-tv-v0.3.6.keystore`、`signing.properties` 和 `SIGNING-IDENTITY.json`。
- NAS 发布维护账号的私密主目录 `~/.javjaeger-tv-signing/v0.3.6/signing-backup.tar`，包含相同的三个文件；SSH 连接信息见 [部署说明](../DOCKER.md#当前本地部署环境)。该备份位于 Docker 和网站目录之外。

目录权限为 `700`，文件权限为 `600`，两处备份已做回读比对。系统重装或机器迁移前保留外置盘副本；需要从 NAS 恢复时，将归档中的三个文件解包到仓库之外的私密目录，恢复上述权限，再运行 `verifyTvSigning`。不要在缺少签名时生成替代密钥。

v0.3.6 的公开证书 SHA-256 指纹为：

```text
e436292d609251b8b847f6d488821265ca03171809e34cb78e242c96fbe6e41c
```

构建会检查私钥、口令、别名和该指纹；配置或密钥缺失、无法解锁、证书不一致时停止构建。私密配置和密钥必须留在 Git 之外，不上传到 Release。原始 `~/.android/debug.keystore` 仅保留为额外副本，发布构建不再依赖它。

修改签名构建流程时，运行 `python3 tests/android_tv_signing_check.py`。该隔离检查使用临时生成的假密钥验证失败保护和开发签名限制，无需真实账号；临时目录默认使用 `/Volumes/dev1/codex/tmp`，其他机器可用 `JAVJAEGER_TV_SIGNING_TEST_TMP` 指向仓库之外的可写目录。

## 隔离工作流回归

启动一个一次性 Android TV 模拟器后，在仓库根目录执行：

```bash
python3 tests/android_tv_smoke.py --serial emulator-5556 --apk android-tv/app/build/outputs/apk/debug/app-debug.apk
```

只验证本地播放、中文字幕开关、样式和分段切换时，附加 `--playback-only`。字幕检查会在暂停时用遥控器关闭再打开，调整字体、字号与底部留白，并核对画面变化、设置保存和恢复默认，以及视频没有重新请求。

进度条与控制层回归使用 Android 自带的 Instrumentation，无需额外测试库。先在 `android-tv/` 执行 `./gradlew assembleDebugAndroidTest`，再在上面的回归命令后附加 `--seek-only`。测试分别检查本地与会话所属的在线播放：控制层快速隐藏、遥控器操作后重新计时、顶部焦点回收、暂停时保持显示、系统栏全屏，以及顶部操作栏到进度条的焦点路径、全屏与进度条上的左右键立即前进或后退 30 秒、片头片尾边界、实际拖动定位和暂停状态保留。定位测试使用预先生成的两分钟合成视频，运行时仍无需 FFmpeg。测试 APK 位于 `app/build/outputs/apk/androidTest/debug/`，不会包含在安装给电视的应用 APK 中。

脚本只接受模拟器，会清空模拟器中 JavJaeger TV 的应用数据。它启动临时 HTTP 服务，用横图、竖图、方图合成封面、合成影片和已保存的测试视频验证原图比例、收起式导航、连接、内容区域占比、标签组合、演员和 VR 浏览、分页、搜索、遥控器导航、缺失分段跳过、本地与在线播放、115 会话及取消重试，不访问真实服务器、账号或媒体库。运行时不需要 FFmpeg；测试 MP4 是预先生成的纯色无声视频。

默认将请求记录、界面树与截图保存在 `/tmp/javjaeger-tv-smoke/`。单元测试另外验证筛选、排序、分页、元数据解析、服务器地址校验、固定播放地址、错误脱敏及网络响应大小限制。

## 源码边界

`app/src/main/java/com/javjaeger/tv/` 负责原生界面、HTTP 数据读取和 Media3 播放。客户端调用已有的 `/api/movies/local-library` 本地影院接口、`/api/movies` 发现与详情、`/static/actors.json` 和 `/static/categories.json` 目录、`/api/automation/play-jobs` 和 `/api/system/jobs` 播放准备接口，以及 `/api/system/info` 部署信息和 `/api/image-proxy` 图片代理；不复制 Python 服务或网页运行时。下载、刮削、自动化等管理操作仍通过网页完成。服务端和浏览器 bundle 继续按仓库原有流程构建。
